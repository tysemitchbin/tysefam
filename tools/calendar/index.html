    ➕ Add a calendar

    Google gives every calendar a private link. Copy it once and this page keeps up by itself. You need a computer for this (the Google Calendar phone app doesn't show the link).

    1. Open Google Calendar settings.
    2. On the left, under Settings for my calendars, click the shared calendar.
    3. Scroll down to Integrate calendar and copy the Secret address in iCal format (click the eye 👁 to show it, then copy).
      Can't see it? Only the calendar's owner (or someone allowed to “make changes and manage sharing”) can.
    4. Paste it below. It's saved somewhere only the site's server can read, never in the website's code.
